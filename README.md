# Работа Бандита 1.3 — JSON / Railway

Версия полностью без базы данных: SQLite, PDO, schema.sql и DB_PATH не используются.

## Railway

В корне проекта должен находиться Dockerfile. Railway собирает приложение из него.

Variables:

```text
BOT_TOKEN=токен_бота
MAIN_ADMIN_ID=числовой_Telegram_ID_админа
```

Опционально:

```text
WEBHOOK_SECRET=...
CRON_SECRET=...
```

Start Command в Railway оставь пустым — команда запуска уже указана в Dockerfile.

## Хранение

Игровые данные хранятся в JSON-файлах каталога `data/`. Каталог создаётся автоматически.

## Админка

`/safonof` → `💎 VIP`

Выдача премиума:

```text
/premka ID УРОВЕНЬ ДНИ
```

Пример:

```text
/premka 123456789 5 30
```

Уровни:

1 — VIP Уличный — 200 Респектов
2 — VIP Авторитет — 500 Респектов
3 — VIP Криминальный босс — 1000 Респектов
4 — VIP Главарь — 2000 Респектов
5 — VIP Легенда — 5500 Респектов

Снять VIP:

```text
/unvip ID
```

`/vip ID УРОВЕНЬ ДНИ` тоже поддерживается как алиас `/premka`.

## Важно

Если Telegram-группа должна учитывать обычные сообщения для VIP-задания «30 сообщений», отключи Group Privacy у бота через @BotFather.
