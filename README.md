## Railway

1. Создай Railway Service из проекта.
2. Используй приложенный `Dockerfile`.
3. Добавь Variables:
   - `BOT_TOKEN` — токен Telegram-бота.
   - `MAIN_ADMIN_ID` — Telegram ID главного администратора.
   - `DB_PATH=/data/bot.sqlite`.
   - `WEBHOOK_SECRET` — необязательно.
   - `CRON_SECRET` — рекомендуется для автоматического завершения событий.
4. Добавь Railway Volume и смонтируй его в `/data`.
5. Включи публичный Railway Domain.
6. `start.sh` сам выставит Telegram webhook. При наличии `CRON_SECRET` он также проверяет завершённые события примерно раз в минуту.

## VIP

Главный администратор/администратор:

- `/vip ID DAYS` — выдать VIP и начать новый цикл VIP-заданий.
- `/unvip ID` — снять VIP.
- `/respect ID SUM` — изменить Респекты.

Игрок открывает `👤 Профиль → 💎 VIP-задания` и получает доступные награды после выполнения условий.

## Рассылка

Только для администраторов:

- `/broadcast_users текст` — отправить в ЛС всем зарегистрированным пользователям.
- `/broadcast_chats текст` — отправить во все активные зарегистрированные группы/супергруппы.
- `/broadcast_all текст` — отправить и пользователям, и группам.

Бот должен иметь возможность писать в группу. Заблокированные/недоступные чаты автоматически помечаются неактивными.

## События

Создать:

`/event_create Название | Описание | YYYY-MM-DD HH:MM | деньги | респекты | победители`

Пример:

`/event_create Большой розыгрыш | Забери награду! | 2026-12-31 23:59 | 100000 | 20 | 3`

Дополнительно:

- `/event_list` — список событий для админов.
- `/event_end ID` — досрочно завершить событие и выбрать победителей.

После окончания выбираются случайные уникальные участники в количестве, указанном при создании. Победители получают награду и уведомление в ЛС.

## Активность в чатах

Для задания «30 сообщений» бот должен получать обычные сообщения групп. В BotFather отключи Group Privacy (`/setprivacy` → Disable) и добавь бота в нужные группы.
