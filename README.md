# Работа Бандита 1.3 — Railway

Чистая сборка: PHP 8.3 + SQLite + Telegram Bot API. Python не используется.

## Railway Variables

- `BOT_TOKEN` — токен Telegram-бота
- `MAIN_ADMIN_ID` — Telegram ID главного администратора
- `DB_PATH` — `/data/bot.sqlite` (рекомендуется)
- `WEBHOOK_SECRET` — необязательно
- `CRON_SECRET` — необязательно, нужен для автоматического завершения событий

Токен и ID не хранятся в коде. `config.php` читает их через `getenv()`.

## Что есть в 1.3

- VIP-система и VIP-задания:
  - 5 работ → 4 500 бабок
  - 3 ограбления → 10 000 бабок
  - 30 сообщений → 15 000 бабок + 10 Респектов
- Респекты как отдельная валюта.
- События/розыгрыши с автоматическим случайным выбором победителей и выдачей наград.
- Раздел «Мои бизнесы → Свой магазин».
- Активность игроков в группах.
- Админ-панель: пользователи, деньги, статистика, рассылка, события, VIP, чаты, администраторы.
- Рассылка: `/broadcast_users`, `/broadcast_chats`, `/broadcast_all`.
- Список групп в «💬 Чаты бота» и ручное включение/исключение из рассылки.
- Информация для новичка показывается только при первом `/start` после регистрации.
- Исправлены ошибки старой рассылки и проверка результата Telegram API.
- Автоматическое завершение событий через `CRON_SECRET`.

## Первый запуск

1. Добавь переменные в Railway.
2. Добавь Persistent Volume и используй `/data/bot.sqlite`.
3. Deploy.
4. Бот автоматически установит webhook на `RAILWAY_PUBLIC_DOMAIN`, если Railway его предоставляет.
5. Для подсчёта сообщений в группах отключи Group Privacy у бота через BotFather.

## Админ-команды

`/safonof` — админ-панель.
`/give ID SUM`, `/take ID SUM`, `/setmoney ID SUM` — деньги.
`/vip ID DAYS`, `/unvip ID`, `/respect ID SUM` — VIP и Респекты.
`/broadcast_users ТЕКСТ`, `/broadcast_chats ТЕКСТ`, `/broadcast_all ТЕКСТ` — рассылки.
`/event_create Название | Описание | YYYY-MM-DD HH:MM | деньги | респекты | победители` — создать событие.
`/event_list` — список событий.
`/event_end ID` — завершить событие и выбрать победителей.
